**DSH 插件（alpha.42 系列后续版本）的安装包请前往 [podplo-dsh-plugin](https://github.com/jacksia0409/podplo-dsh-plugin)。**

历史独立桌面 App 版本 0.1.15、0.1.16、0.1.19、0.1.20 的安装产物保留为草稿，尚未完成公开分发前的脱敏，不对外开放下载。
原先放在这里的 DSH 插件 Release 已迁至独立插件仓库，原附件保留为草稿。
本仓库没有上传客户端源码。
